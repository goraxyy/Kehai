# The message to each tester

`make_codes.py` fills this in for each tester: `{code}`, `{round}`, and the links from
`tools/playtest/.env` (`{itch_url}`, `{itch_password}`, `{mac_link}`, `{windows_link}`,
`{form_url}`). A line whose download isn't set up is left out. Everything below the line is the
message.

---

Hi! Thanks for playtesting Kehai, a night shift in a convenience store where the store's
management AI, Karen, learns your habits.

Your tester code: {code}

Download it:
- itch.io: {itch_url} (password: {itch_password})
- Mac: {mac_link}
- Windows: {windows_link}

Opening it the first time:
- Mac: unzip, open Kehai. If macOS says it can't check it, go to System Settings → Privacy &
  Security, scroll down, and click Open Anyway.
- Windows: unzip the whole folder and run Kehai.exe. If Windows SmartScreen appears, click More
  info → Run anyway.

Then:
1. Type your code when the game asks. It keeps your sessions together; your name never goes in.
2. Play up to three shifts, about 20–30 minutes. Headphones help: Karen makes sounds.
3. Please don't look anything up first. Not knowing what to do is exactly what I want to see.
4. If something breaks, press Shift+F7 and write one line about it.
5. At the end there are four quick questions in the game, then a link to a few longer ones:
   {form_url}

The game asks whether to send your session (what happens in the game, never your camera,
microphone or screen). Sending it lets me watch your session as a 3D replay, which helps more
than anything. Thank you!
