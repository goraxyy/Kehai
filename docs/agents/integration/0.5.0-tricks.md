# 0.5.0 trick implementation handoff

Five appended tactic IDs: `flash_sale`, `screen_loop`, `room_lights`, `freezer_alarm`,
`complaint`. TaskManager and the in-game guide expose their jobs; `TrickCheck` includes them.
The test harness now begins at shift 4, rather than an unreachable tenth shift of a four-shift game.

- FlashSaleState/SaleRules: normal cap 2, sale cap 4, arrival delays unchanged. ClosingMic's
  20-second hold ends it, PA off does not. Closing and shift cleanup end it without counting
  an employee repair. ShiftManager resets fixtures and installs the normal cap.
- Screen loop freezes a real empty camera render and its timestamp while leaving the live
  SightSensor unchanged. Headless execution retains logical clock/effect state without textures.
  The physical backstreet camera box is the repair target for both loop/break.
- Room switches flicker twice and control real room lights plus LightProbe. Both the human
  answer sheet and bots reduce target visibility in an unlit room; an actual held torch beam
  can illuminate her. Baseline perception is unchanged until a room switch is off.
- Freezer alarm uses a physical cold-room door. Both actors' step noise and footstep audio
  are masked locally; closing that door ends it. Normal door uses still work.
- Complaint uses an existing eligible shopper, never an extra spawn. The shopper walks to
  the till and can be heard out by holding E 20 seconds. `HeardOut` distinguishes success from
  impatience. EpisodeMetrics counts a failed complaint once, without duplicating checkout loss.
- No chore tactic starts after doors close. Training presentation/TMP factories in KarenScreen,
  CctvWall and the existing fixture paths are guarded by Edition.ShowUI; logical sensors remain.

Parent integration: EnvWorld exposes stable episode targets and chore kinds; SimulatedPlayers
maps them to `call_off_sale`, `reset_screen`, `restore_room_lights`, `close_freezer`,
`hear_complaint`; KehaiEnv approaches and uses the same press/hold objects as a person.
Employee observations include all chores. AI response timers subscribe to actual world events,
so automatic cleanup, disabled fixtures and complaint timeouts do not become successful repairs.

Validation: `python3 tools/tricks/check_phase1_rules.py` ran **74 checks of production C# policy
arithmetic**, without Unity. Full editor/runtime/test sources compile against installed Unity
libraries, including player edition branches. Native EditMode tests, the real trick check,
correct placement of generated fixtures, render output, hands-on reach and the paired fairness/
stuck/game-feel run are **not run**. Do not treat this handoff as evidence of in-scene success.
