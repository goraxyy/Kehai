## Native regression suite

The initial run passed 525 of 538 tests. Thirteen failures exposed stale trick-count/end-shift
assertions, EditMode registration/destruction assumptions, and a bot sight observation that
incorrectly required a real Karen brain. The fixes are covered by the final suite. After the
map rebuild fix, another run passed 538 of 539: the replay still opened the authored store
instead of reconstructing the recorded Labyrinth shelves.

New recordings use `.krec` version 4 with an explicit layout ID. Playback reconstructs that
layout before claiming shelf actors/slots; hidden authored bays cannot stand in for generated
bays. The Labyrinth end-to-end test now matches all 206 shelf units, all 24,700 slots and all
240 lights. Three additional legacy-header cases verify versions 1–3 still read as the original
store. This proves one new-layout replay path, not every camera/render/layout combination.

Final suite: **542 passed, 0 failed, 0 skipped**, Unity exit 0. Local artifacts:
`/private/tmp/kehai-050-unity-handoff/editmode-replay-verified.xml` and `.log`.
